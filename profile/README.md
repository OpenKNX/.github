# Über OpenKNX

OpenKNX ist eine Gemeinschaft von KNX-Enthusiasten, die freie Firmware, ETS-Applikationen und KNX-Geräte entwickeln.\
Um eine nachhaltige und professionelle Integration ins Smarthome zu erreichen streben wir eine größtmögliche Kompatibilität zum KNX-Standard an.\
Mit OpenKNX hast Du die Möglichkeit bereits fertige Lösungen einzusetzen, diese individuell anzupassen oder ganz neue Lösungen zu realisieren - der modulare Ansatz bietet schnelle Erfolge durch den Einsatz bewährter Softwaremodule.
